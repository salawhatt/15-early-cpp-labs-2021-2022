# Ранние работы на C и C++
- 'vfs' — учебная виртуальная файловая система. Откройте 'VFS.sln'. Программа использует 'file_system.txt' в рабочей папке.
- 'configurator' — консольный конфигуратор. Откройте 'Konfig.sln'. Для чтения прайса и импорта используются 'Price.txt' и 'Import.txt' в рабочей папке. Примеры обоих файлов лежат рядом с решением.
- 'console-xo' — консольные крестики-нолики. Откройте 'ConsoleXO.sln'.
